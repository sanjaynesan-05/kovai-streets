Add cinematic main menu with live city background

Replace the old start screen with a left-side game menu: Continue,
New Game, Load Game, Settings, Controls, Credits and Exit.

- Background: a slow golden-hour camera over the real game city,
  using the existing renderer, plus city ambience sounds
- Story panel shows the current act, next mission and story progress
  calculated from the save (no hard-coded values)
- Continue loads the existing save and shows when it was last played;
  a new-player layout appears when there is no save
- New Game asks for confirmation and keeps the old save as "previous"
- Load Game lists the save system's three slots (current, autosave
  backup, before last New game); loading keeps the current save
- Settings use the shared settings store: graphics, fullscreen,
  master and music volume, camera sensitivity, invert look, subtitle
  language
- Controls screen lists the real key bindings and touch controls
- Credits screen
- Exit explains that browsers can't close their own tab
- Pause menu gets a "Main menu" button that saves first
- Keyboard (arrows, Enter, Escape), mouse and touch input;
  responsive layout for short and narrow screens
- Vehicle regression tests moved to a road without traffic
